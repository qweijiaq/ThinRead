## 正文

这不是一个把书压成几句话的摘要工具。我把这套流程做成了一个本地桌面工具，名字叫页边。

· 逐章读薄：按断言重写整章，保留论证链，删铺垫不删观点。
· 核心卡片：5–25 张，写清在文中的作用与原文依据。
· 原文核对：引文逐字匹配，找不到就不标「已核对」。
· 整本成书：合并、润色，导出 Markdown / HTML / PDF / 发布包。
· 知识地图与人物关系图：卡片长成概念网，小说人物连成关系图；另有分享卡、小红书图文和双人播客。

它不替你读书，只把读过的部分留下来。

边界也说清楚：macOS 桌面端，未签名；模型和音色自带 Key；在线音色与播客需要联网或付费服务。现在是小范围内测，敬请期待。

## 逐页文案

### 01 封面

读完了，却什么都写不出来。

把一本书读成能发布的稿子，而不是再堆一堆划线。

本地优先 / 自带 API Key / macOS 桌面端

### 02 它是什么

不是摘要，是读薄。

摘要把书压短；读薄把作者的主张留下来，再变成能继续写的东西。

01 读薄：按断言重写整章，删铺垫，不删观点。
02 卡片：5–25 张，写清作用与原文依据。
03 成书：把章节合成一篇有结构的文章。

### 03 核心能力一

先读薄，再谈记住。

打开一章，点「读薄并提炼」。原文先变成可发布的读薄稿，再从稿子里提炼卡片。

A 原文：断言、论证链、边界都留下。
B 读薄：并列改列表，删重复，不删观点。
C 卡片：用「不知道它是否影响理解」筛选。

### 04 核心能力二

每张卡，都要能回到原文。

卡片不是金句。它要写清在文中的作用；原文依据必须能逐字找到，找不到就不打「已核对」。

5–25 张核心卡片 / 1/1 依据核查 / ≤3 条有限延伸

### 05 人物关系图

一张图，看清人物怎么连。

人物、组织、地点和事件从原文里被抽出来，连成一张可点击的图。谁在隐瞒，谁在保护谁，一眼能看明白。

01 39 个节点 · 108 条关系：《恶意》实测，人物、组织、地点、事件都进图。
02 点开一个人：右侧看他和谁有关、关系是什么、出处在哪。
03 导出：PNG、Mermaid、Markdown，都可以带走。

### 06 关系与生态

一本书，应该连回其他书。

读薄、卡片、知识地图、成书、分享和播客，共用同一份本地数据。

01 知识地图：概念从卡片里长出来，可以只看跨书概念。
02 人物关系：小说里的角色、阵营和动机连成一张图。
03 双人播客：把一章变成 A/B 对谈稿，生成后可直接播放。

### 07 数据与边界

数据留在本机。

书、笔记、向量索引和备份都在本地；模型与音色由你自带 Key。

01 本地：SQLite、书文件、备份都在本机；恢复前还会再做一份安全备份。
02 模型：DeepSeek、Claude、OpenAI 等，按任务分别指定；Key 用系统钥匙串加密。
03 边界：macOS 未签名；Windows / Linux 未发布；在线音色与播客需要联网或付费服务。

### 08 收尾

读完一本书，应该留下能用的东西。

不是更多划线，而是一篇能发的稿、几张能回看的卡、一张能连起来的网。

它不替你读书，只把读过的部分留下来。
